# x-digest 功能点清单

> 生成日期：2026-10-28　|　分支：muse-dev　|　依据：README、backend/frontend 源码与路由
> 技术栈：Nuxt 4（Vue 3）+ Go（net/http）+ MariaDB；部署 nginx 18089 → Nuxt 18091 / Go 18093

| 模块 | 功能点 | 优化意见 | 新增意见 | 备注 |
|---|---|---|---|---|
| X 日报 · 列表 | 帖子卡片列表（标题、摘要、作者头像、发布时间、标签、行业/技术、显示更多/收起） | 首屏仍是 SSR 外壳 + 客户端拉取，建议接通 SSR 直出首屏，改善首屏速度与 SEO | 支持无限滚动/分页加载，替代一次拉 1000 条 | `pages/index.vue`、`GET /api/v1/posts` |
| X 日报 · 筛选 | 按作者、平台标签、类别、用户标签、关键词（支持 `标签:`/`tag:` 前缀）、日期范围筛选；筛选区折叠、chip 展开状态记忆 | 筛选目前在前端执行（拉 page_size=1000），数据量增长后会变慢；后端过滤参数已实现，建议改为服务端粗筛 + 分页 | 保存常用筛选组合（"视图"），一键切换 | 选中状态存 localStorage |
| X 日报 · 分类 | 自定义类别 CRUD，帖子可归属多个类别 | 缺少类别改名、撤销删除（README 已列为未复刻）；建议补齐 | 批量归类（多选帖子 → 归入类别） | `/api/v1/categories`、`/categories/assignments` |
| X 日报 · 用户标签 | 给帖子打自定义标签，可按标签检索 | `/tags` 用 `utf8mb4_bin` 导致 `workbuddy`/`Workbuddy` 等大小写变体重复（408 个），建议增加标签归一化/合并工具 | 标签云/热度统计；标签别名映射 | `/api/v1/user-tags` |
| X 日报 · AI 摘要 | 卡片「✨ AI 摘要」：首次后台生成（全文摘要、要点、提及资源），之后读库；可重新生成 | 原文不在 posts 表，需前端在 POST 体带 `{text, links}`，易出现前后端数据不一致；建议原文入库后由后端自取 | 支持批量为选中帖子生成摘要；摘要中英切换缓存 | `post_summaries` 表，`/posts/{id}/summary` |
| X 日报 · 导入单帖 | 粘贴 x.com 链接 → fxtwitter 拉原文（长文/引用/回复/图片）→ AI 解析 → 入库；作者未关注则自动加入「默认」分组 | 无鉴权，任何访问者都可触发 AI 调用和写库，需加鉴权 | 支持一次粘贴多条链接批量导入 | `POST /api/v1/posts/import`、`XImportDialog.vue` |
| X 日报 · 更新帖子 | 选账号后台任务：Grok `x_search` 找新帖 id → fxtwitter 拉原文 → AI 解析入库；短回复（≤15 字）跳过；页面轮询进度 | 任务状态只在内存（goroutine），服务重启即丢失；建议持久化任务表并支持断点续跑 | 定时自动刷新（cron/systemd timer），无需手动点击；失败帖子重试列表 | `POST/GET /api/v1/x/refresh`，依赖 `GROK_API_KEY` |
| X 日报 · 立即更新（Webhook） | 调用用户配置的外部更新器，URL/Key 存浏览器 localStorage | 与「更新帖子」功能重叠，建议评估后下线或合并，减少入口 | — | 设置弹窗 → Webhook |
| X 日报 · 翻译 | 中英内容翻译（DeepSeek 中转），界面中/英切换 | 翻译结果建议落库缓存，避免重复调用 | 原文/译文对照显示 | `/api/v1/translate`、`useTranslate.ts`、`utils/i18n.ts` |
| 关注列表 | 分组 + 账号 CRUD（固定分组不可删，删组后作者归入 other），头像回退 | 头像依赖仓库内静态文件 `avatars/`、`public/avatars/` 两份重复，建议统一存储/CDN | 账号活跃度统计（近 30 天发帖数）；从 X 关注列表一键导入 | `/api/v1/watchlist`、`config/watchlist.json` |
| 复刻（教程跟做） | 从教程帖按步骤快照建复刻；步骤 idle/active/done 三态；子步骤增删；排序（时间/进度）；同帖不重复建 | 仅"教程/技术分享"显示复刻，判定依赖启发式，建议允许用户手动开启/关闭 | 复刻进度看板/完成率统计；导出为 Markdown 清单 | `pages/fuke.vue`、`ReplicaStepNode.vue`、`/api/v1/replicas` |
| 复刻 · 笔记 | 每步备注编辑器（textarea + 工具栏 + marked 预览）、备注翻译 | 自研编辑器能力有限，建议引入成熟 Markdown 编辑器并注意 XSS 过滤 | 备注支持粘贴图片自动上传为附件 | `NoteEditor.vue` |
| 复刻 · 附件 | 每步上传附件（白名单扩展名、≤10MB）、预览（图片/PDF/Office/文本）、下载、删除 | PDF 用原生 embed、PPTX 图片未按 slide 映射、xls 仅下载；无鉴权时可被他人上传垃圾文件 | 附件总容量配额与清理任务 | `AttachmentPreview.vue`，磁盘 `/var/lib/xdigest/attachments` |
| 自定义流程 | 在复刻页新建自定义流程并添加步骤（非帖子来源） | — | 流程模板复用/复制 | `fuke.createFlow` |
| GitHub 仓库 | 仓库卡片（描述/语言/星标/Fork/Issue/PR 数/更新时间）、最近 10 条提交、最新 Release、README 简介与教程步骤解析；分组、标签、备注、排序；单仓刷新 + 全部同步；限流提示 | 同步只在手动时触发；全部同步在未配 `GITHUB_TOKEN` 时易触发 60 次/小时限流，建议排队 + 退避 | 定时同步；新 Release 提醒；从仓库教程一键建复刻 | `pages/repos.vue`、`internal/github`、`/api/v1/repos` |
| 油管视频 | 频道 CRUD + 分组、同步时间范围、按账号分组折叠展示；视频/短视频/直播 Tab；单视频按 URL 添加（single 模式频道）；自动标签（关键词规则）；提及资源 | YouTube handler 早于 videoHub、两套实现并存，建议迁移到统一的 hubPlatform | 观看/已读状态标记；稍后观看清单 | `pages/youtube.vue`、`VideoHub.vue`、`internal/youtube`，依赖 yt-dlp + 代理 |
| 油管/B站 · AI 摘要 | 字幕优先（人工 > 原语言自动）→ 全文摘要、要点、带时间点章节（保留作者章节）；无字幕时仅用标题简介并注明；202 + 4 秒轮询 | 轮询可改 SSE 推送；共享任务池并发上限建议可配置 | 章节点击跳转到对应播放时间（内嵌播放器） | `yt_video_summaries`、`internal/ytsummary` |
| B 站视频 | 与油管共用页面与接口形态（UP 主解析、同步、分组、摘要） | — | 抖音/小红书等平台按 hubPlatform 接入 | `pages/bilibili.vue`、`internal/bilibili`、`/api/v1/bili/*` |
| 视频评论 | 热门评论接口（油管/B站） | 页面已不再调用，接口与 worker 仍运行，建议下线或开关控制以省资源 | — | `/api/v1/<yt\|bili>/comments` |
| 设置 | 主题深/浅色、字体、字号、语言、Webhook、关注列表、用户标签管理（弹窗） | 设置仅存浏览器，多设备不同步 | 设置云端同步（需先有账号体系） | `useSettings.ts` |
| 数据流水线 | `cmd/digest`：raw_posts.json → AI 生成 posts.json（断点续跑、短回复跳过、Grok 兜底）；`cmd/import`：JSON → DB 幂等导入；raw 写入去重脚本 | `data/` 已达 37MB 且 bot 每次提交整个 posts.json，仓库膨胀；建议数据移出 git（对象存储/DB 直写） | 导入结果校验报告（新增/跳过/失败数） | `backend/cmd/digest`、`cmd/import`、`scripts/append_raw_posts.py` |
| 后端 · 架构 | 标准库 HTTP、统一 JSON 错误、`/healthz` 含 DB ping | `cmd/api/main.go`（1741 行）、`store/store.go`（2168 行）过大，建议按领域拆分（posts/watchlist/replicas/repos/video） | 结构化日志 + 请求指标（Prometheus） | — |
